# 《下一班火车》

你是初级工程师。这一局画在一台掌机里：方向键选牌，A 确认，B 返回，Start 看玩法说明。画面上一直有精力、理智、人情、天数、审计和班次。当前卡点会亮起来，并写明为什么卡住、用什么牌能过。

每回合摸 4 张牌。去问问会多一个签字，但能问出隐藏要求或换回人情。拉通对齐能指出真负责人，或并掉一个节点，抄送的人不用再签。休息能补精力和理智。错过这班，审批清零（老板进度和已通过的名字会留下），过关还会补一点资源。种子写在标题画面上，`?seed=` 可以复现。

这是独立的小演示，不替换旁边的「准点发车」。

## 怎么玩

先选一个很小的改动：按钮改色、错别字，或注释里的句号。

每一关是一班车。手牌要花精力和人情，并且过一天：

| 牌 | 作用 |
| --- | --- |
| 去问问 | 多一个节点。问出隐藏要求，或人情 +1。 |
| 拉通对齐 | 指出真负责人，或并掉一个节点，同时再抄送一个人。 |
| 向上管理 / CC大老板 | 通过一个节点，掉一点理智。 |
| 偷换概念 | 标题改成体验优化。合规对峙时，特批才不被按住。 |
| Hotfix特批跳过 | 跳过普通签字。失败只掉 1 点精力。成功抬高审计，审计格盖不过。 |
| 周末突击 | 亲手通过当前卡点。打在卡夫卡身上，这一回合不再长表格。 |
| 休息 | 精力 +4，理智 +1。不签字。 |

流程卡夫卡不处理就会再长一张补充材料。薛定谔的负责人藏在两三个名字里，对齐之后才露出真身。影子架构师会把你打出的第一张牌按回去，只此一次。VP 评审会要你选：自己去、助理代开，或者不去。理智归零会请你去当流程负责人，拒绝的话理智会回来一点。三个开头改动不一样：改颜色签字更多并惊动架构师，改错别字最轻，补句号会召出安全负责人。

四关签字更多、时间更短：修错别字、版本大联调、红线行动、封网期大促。

第 1 关只在「文案负责人」名下时，打出「周末午夜突击」就能进第 2 关。三条结局都能走到：

- 荒诞胜利：一行合并了，业务其实已经砍了这个按钮，当天上线当天被撤。
- 黑化结局：你坐到流程负责人的位子上，给下一班再加一道卡点。
- 虚无结局：合规报告 100 分，几个月没有东西上车，竞品先上了。

精力归零会辞职。天数归零，这班不要你，审批清零。安全要日志、合规不让记，还硬要合入，就是合规死锁。

## 本地运行

在仓库根目录：

```bash
npm test
npm start
```

浏览器打开 http://127.0.0.1:3000/next-train/

`npm test` 会先跑原来的发车游戏，再检查这一款：第 1 关能进第 2 关，三种结局和三种失败都到得了。

单文件页面：

```bash
npm run build:next
```

生成 `next-train/play.html`，给不能加载相对路径脚本的预览站用。
